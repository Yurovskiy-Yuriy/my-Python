
# «Web-scrapping»


Нужно парсить страницу со свежими статьями и выбирать те статьи, в которых встречается хотя бы одно из ключевых слов. Эти слова определяем в начале скрипта. Поиск вести по всей доступной preview-информации, т. е. по информации, доступной с текущей страницы и по всему тексту статьи целиком. Для этого потребуется получать страницы статей и искать по тексту внутри этой страницы.
Выведите в консоль список подходящих статей в формате: <дата> – <заголовок> – <ссылка>.
