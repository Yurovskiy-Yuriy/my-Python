# Автоматизация сетевых устройств (Dionis NX / Linux-based)

Скрипты для автоматизации сетевых устройств (Dionis NX / Linux-based) с использованием трёх библиотек.

```
├── netmiko_script.py # Netmiko (рекомендуется)
├── paramiko_script.py # Paramiko (низкоуровневый SSH)
├── scrapli_script.py # Scrapli (асинхронный подход)
├── dionis_single_thread.py
├── dionis_multithread.py
└── dionis_auto_connect
    ├── data_files
    |      └── devices.yaml
    ├── templates
    |     ├──  dst_template.txt
    |     └──  src_template.txt
    └── main.py
```

### netmiko_script.py, paramiko_script.py, scrapli_script.py

Назначение:
Все три скрипта выполняют **одни и те же задачи**, но разными способами:
- Читают конфигурацию устройств из файла `devices_3.yaml`
- Подключаются к каждому устройству по SSH
- Выполняют команды `show` и `show version`
- Сохраняют вывод в файлы `test_<host>.txt`
- Обрабатывают ошибки подключения и аутентификации

### dionis_single_thread.py (Последовательное выполнение)

Назначение:
Поочерёдное подключение к устройствам Dionis NX с выполнением команд и сохранением результатов.

Особенности:
 - устройства обрабатываются одно за другим
 - для каждого устройства создаётся отдельный TXT-файл

### dionis_multithread.py (Многопоточное выполнение)
Назначение:
Параллельное подключение к нескольким устройствам Dionis NX для максимальной производительности.

Особенности:
- одновременное выполнение команд на 10 устройств 
- результаты пишутся сразу после выполнения
 легко переключаться между show и config режимами


### dionis_auto_connect

Скрипт автоматизирует настройку сетевой доступности между двумя маршрутизаторами Dionis NX. 
Он подключается к устройствам по SSH, собирает информацию о существующих интерфейсах
(через команду show), анализирует вывод и автоматически находит первый свободный порт
на обоих устройствах. Затем с помощью шаблонов Jinja2 генерирует конфигурационные 
команды для назначения IP-адресов из одной подсети (192.168.100.1/30 и 192.168.100.2/30) 
на найденные свободные порты, обеспечивая тем самым прямую IP-связность между маршрутизаторами.
Таким образом, скрипт полностью автоматизирует процесс создания сети между двумя роутерами без ручного вмешательства.
