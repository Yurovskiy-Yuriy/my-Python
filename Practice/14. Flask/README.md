# Flask Ads API

Простое REST API для управления объявлениями, реализованное на Flask.

## Возможности

- Создание объявления
- Получение объявления по ID
- Редактирование объявления
- Удаление объявления

## Поля объявления

- `id` — уникальный идентификатор (генерируется сервером)
- `title` — заголовок объявления
- `description` — описание объявления
- `owner` — владелец объявления
- `created_at` — дата и время создания (UTC, ISO 8601)

## Установка и запуск

1. Создайте виртуальное окружение (если ещё не создано):

   ```bash
   python -m venv env
   ```
2. Активируйте окружение:

   - Windows (PowerShell):
     ```bash
     .\env\Scripts\activate
     ```
   - Установите зависимости:
3. ```bash
   pip install flask
   ```
4. Запустите сервер

   Сервер будет доступен по адресу:
   `http://127.0.0.1:5000`

## API

Все запросы и ответы используют формат JSON.

### POST /ads — создать объявление

**Запрос:**

```http
POST http://127.0.0.1:5000/ads
Content-Type: application/json

{
  "title": "Продам велосипед",
  "description": "В хорошем состоянии",
  "owner": "Иван"
}
```

**Ответ (201 Created):**

```json
{
  "id": 1,
  "title": "Продам велосипед",
  "description": "В хорошем состоянии",
  "owner": "Иван",
  "created_at": "2026-09-07T17:00:00.000000+00:00"
}
```

---

### GET /ads/<id></id> — получить объявление по ID

**Запрос:**

```http
GET http://127.0.0.1:5000/ads/1
```

**Ответ (200 OK):**

```json
{
  "id": 1,
  "title": "Продам велосипед",
  "description": "В хорошем состоянии",
  "owner": "Иван",
  "created_at": "2026-09-07T17:00:00.000000+00:00"
}
```

**Ответ, если объявление не найдено (404 Not Found):**

```json
{
  "error": "Объявление не найдено"
}
```

---

### PUT /ads/<id></id> — редактировать объявление

Можно передавать только те поля, которые нужно изменить.

**Запрос:**

```http
PUT http://127.0.0.1:5000/ads/1
Content-Type: application/json

{
  "title": "Продам велосипед (обновлено)",
  "description": "Состояние отличное, торг уместен"
}
```

**Ответ (200 OK):**

```json
{
  "id": 1,
  "title": "Продам велосипед (обновлено)",
  "description": "Состояние отличное, торг уместен",
  "owner": "Иван",
  "created_at": "2026-09-07T17:00:00.000000+00:00"
}
```

---

### DELETE /ads/<id></id> — удалить объявление

**Запрос:**

```http
DELETE http://127.0.0.1:5000/ads/1
```

**Ответ (200 OK):**

```json
{
  "message": "Объявление удалено"
}
```

**Ответ, если объявление не найдено (404 Not Found):**

```json
{
  "error": "Объявление не найдено"
}
```

---

## Примеры запросов в формате HTTP-файла

Все запросы находятся в файле `requests.http`:

```http
@baseUrl = http://127.0.0.1:5000

# Создание объявления
POST {{baseUrl}}/ads
Content-Type: application/json

{
  "title": "Продам велосипед",
  "description": "В хорошем состоянии",
  "owner": "Иван"
}

### Получение объявления с id=1
GET {{baseUrl}}/ads/1

### Редактирование объявления с id=1
PUT {{baseUrl}}/ads/1
Content-Type: application/json

{
  "title": "Продам велосипед (обновлено)",
  "description": "Состояние отличное, торг уместен"
}

### Удаление объявления с id=1
DELETE {{baseUrl}}/ads/1
```

## Примечание

Данные хранятся только в памяти процесса Python.
При перезапуске сервера все объявления исчезают.
